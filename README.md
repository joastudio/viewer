# 좋아뷰어 공식 사이트

좋아뷰어의 공개 소개, 개인정보 처리방침, 지원 페이지를 제공하는 GitHub Pages 사이트입니다.

## 공개 주소

- 홈: `https://joastudio.github.io/viewer/`
- 개인정보 처리방침: `https://joastudio.github.io/viewer/privacy.html`
- 지원: `https://joastudio.github.io/viewer/support.html`

## 로컬 실행

```bash
npm ci
npm run dev
```

`main` 브랜치에 푸시하면 GitHub Actions가 정적 사이트를 빌드하고 GitHub Pages에 게시합니다.
